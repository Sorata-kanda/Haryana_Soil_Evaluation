## 🔬 Scientific Approach

### Nutrient Weighting (Agricultural Standards)

```python
weights = {
    'Organic Carbon': 3,    # Soil foundation
    'Nitrogen': 2,          # Primary macronutrient
    'Phosphorus': 2,        # Primary macronutrient
    'Potassium': 2,         # Primary macronutrient
    'Soil pH': 2,           # Affects nutrient availability
    'Micronutrients': 1,    # Boron, Iron, Zinc, etc.
    'Soil Salinity': 1      # Water uptake factor
}
```

### Quality Thresholds

- **Poor:** Score < 4
- **Moderate:** Score 4-6.9
- **Good:** Score ≥ 7

## 📊 Key Findings

### Soil Health Degradation (2016 → 2025)

- Poor: 77.27% → 81.82% (+4.55%)
- Moderate: 22.73% → 18.18% (-4.55%)
- 175 samples degraded from Moderate to Poor

### Critical Nutrient Declines

1. Manganese: -36.4%
2. Sulphur: -35.3%
3. Organic Carbon: -33.7%
4. Boron: -33.0%
5. Iron: -33.0%

### Stable Parameters

- Nitrogen: 0% change
- Soil pH: 0% change
- Soil Salinity: 0% change
